# 不会敲命令，也可以请助手协助搭建

先读 [从零搭建](从零搭建.md) 的第 0 节，知道网站、数据库、Cloud 和机器人分别做什么。你可以一次只搭网站，成功后再接 Cloud 和 QQ。

## 把下面这段话交给能操作本地文件或浏览器的助手

```text
请协助我搭建这个开源字幕协作平台。
先读 README.md、docs/从零搭建.md、docs/验证状态.md 和 SECURITY.md。
请检查我已有什么账号和环境，列出缺少的部分，再分阶段执行。
只使用我明确指定的全新测试环境；不要覆盖现有数据或扩大原账号权限。
用 tools/configure.py 生成我的部署包，不要直接把示例环境上线。
密钥只让我在平台安全表单或本机隐藏输入中填写，不要让我发到聊天。
不要读取或输出密码、验证码、完整令牌、私密稿件和成员资料。
新收费、公开网站、开放端口和重要权限变更，做好具体方案后先问我。
每个阶段告诉我已完成什么、如何验证、哪些还没验证。
不要把离线测试通过描述成云平台已经部署成功。
字幕流程保持人工审批、人工启动 Cloud、自动回传、人工审核。
```

你可以补充已经准备好的环境名称和网站地址。它们不是密码，但不必在公开讨论区张贴内部标识。不要把整份私人配置文件当附件发送。

## 在 Windows 打开命令窗口

打开解压后的项目文件夹，点击资源管理器顶部的地址栏，输入 `powershell` 后按回车。打开的窗口就位于该文件夹。只复制教程中的命令，不要复制行号或提示符。

例如要检查 Python 是否安装，在窗口输入 `python --version`，按回车。看到 `Python 3.11` 或更新版本即可。看到“不是内部或外部命令”时，先安装 Python 并重新打开窗口。

## 如何把部署文件传到服务器

首先确认服务器地址和你有权登录的用户名。下面的命令在**自己的电脑**上运行；先把占位文字替换成真实内容，不要保留尖括号。

```text
scp -r .\build\deployment <服务器用户名>@<服务器地址>:~/subtitle-platform-deployment
ssh <服务器用户名>@<服务器地址>
```

第一条复制文件到该账户的主目录，第二条登录服务器。第一次连接会显示主机指纹；向服务器控制台核对后再接受，不要盲目确认未知主机。登录时密码输入可能不显示字符，这是正常现象。已使用 SSH 密钥登录时按自己的配置处理。

登录后，需要有管理权限的人将部署目录放到教程中的 `/opt/subtitle-platform-deployment`，创建 `/opt/subtitlebot`，安装 Docker 并部署。如果你不熟悉这些步骤，让助手根据服务器实际系统处理；不要套用针对其他操作系统的命令。

AstrBot 管理面板通过 SSH 隧道在本机访问。关闭隧道窗口只会让你暂时无法打开面板；不会关闭服务器上的机器人。

## 出错时提供什么

- 你在教程的哪一步，刚执行了什么操作。
- 报错文字、时间、程序版本，以及已经尝试的办法。
- 遮住密码、完整令牌、邮箱、QQ 身份、未公开稿件后的截图。

公开 issue 适合报告普通故障。发现越权、泄露或可以读取私有数据的问题，按 [安全报告方式](../SECURITY.md) 私下处理，不要公开复现密钥或别人的资料。

当助手表示“已部署”，请让它给出实际地址和验收结果。仅生成 SQL、上传 ZIP 或通过本地测试，都不能证明网站已经可用。
