使用手册：组员、组长和手机操作

这份说明用于已经搭建好的字幕协作台。如果你只是普通组员，不需要购买云服务、创建密钥或安装机器人。

组员：交一份视频，请求云端字幕

  • 1. 打开组长提供的网站，邮箱验证注册。完成注册后，等待组长批准入组。
  • 2. 在“字幕申请与审批”中展开“登记字幕申请”。填写标题、片段时间和说明，选择自己的视频。
  • 3. 视频最长 20 分钟，文件最大 1 GiB。字幕程序会再次检查真实文件时长；更长的视频请事先按内容分段。
  • 4. 等上传完成再离开页面。看到“待审批”表示申请已进入队列；“上传中”不等于已提交。
  • 5. 等组长审批和人工启动。你可以回网站查看自己的申请和项目，不用把视频再发到 QQ。
  • 6. 完成后下载交付文件。ASS 用于保留字幕样式和时间轴，SRT 适合通用播放器；质量报告告诉你哪些位置值得人工复查。

如果发现视频选错，先撤回尚未批准的申请，再重新提交正确版本。被驳回时阅读组长意见。不要为了催进度连续创建相同申请。

组员：做人工翻译、校对、剪辑或封面

在“未认领项目/任务”选择自己能完成的工作。认领项目或首个任务可能使你成为该项目负责人，请确认自己愿意承担协调工作。

任务通常上传的文件
翻译、时间轴、校对字幕文件，例如 ASS
剪辑、压制视频文件
封面图片文件

具体可用扩展名、大小和文件内容必须通过网站校验。不要把视频改名成 .ass 来上传。

交付时填写自己做了什么。每次提交形成新版本，旧稿不会被覆盖。审核退回后根据意见修改并提交新版本。审核通过后，系统按审核事件记录贡献和积分；AI 自动生成不会自动变成人工积分。

组长：审批一份云端申请

先看视频标题、片段、申请人和说明，确认素材有使用权限。再选择可用的云执行身份、时长与请求额度。全平台上限是 20 分钟、文字 400 次、千问识别 40 次；每个作业可以批准更低额度。

这些数字是请求上限，不是保价或预计一定会用完的次数。按量服务的最终费用以实际账单为准。

批准后网站产生独立作业号。QQ 机器人在下一检查时段私聊对应指令，你也可以直接在网站复制，不用等 QQ 才能执行。核对指令中的作业号与申请一致，再到正确的 Cloud 环境新建任务，粘贴整段指令。

网站显示“待人工启动”时，它还没有开始调用模型。Cloud 任务启动后根据自己的进度更新，处理完自动回传字幕及报告。你仍需安排人工审核。

PC 端：配置云执行身份，只需在必要时做

“云执行身份”是网站发给字幕程序的一张受限通行证。身份备注用来辨认；Cloud 环境名是你在 ChatGPT 中选择的工作电脑名称。两边名字相同不会自动配对，密钥相同才会。

已有身份可用时继续使用，不要每处理一个视频就新建身份。

  • 1. 组长在网站进入“云端字幕交付 → 云执行身份设置”。确需新建时填写备注，点击创建。
  • 2. 复制只显示一次的身份密钥，保留此页面直到配置完成。
  • 3. 打开 ChatGPT 网页或桌面端的“设置 → Codex Cloud → 环境”，编辑你实际使用的字幕环境。
  • 4. 在“环境变量 / Manage”中，更新 SUBTITLE_PLATFORM_TOKEN，值就是刚复制的密钥，不加引号或空格。
  • 5. 保存，完成检查并重新发布。从更新后的环境新建任务。
  • 6. 回网站审批时选择生成该密钥的身份。配置完成后清除此页密钥。

环境的其他模型凭据无需因备注修改而改变。更换密钥前先处理旧身份负责的未完成作业；原任务不会自动迁给新身份。

安卓端：日常操作与 Cloud 任务

用 Chrome 或 Edge 打开字幕网站，注册、上传、审批、查看结果的入口与电脑相同。较大视频上传时保持页面在前台，避免系统省电策略中断网络。上传未完成时不要清理浏览器或切换账号。

需要设置 Cloud 变量时，优先用手机浏览器打开 ChatGPT 的 Cloud 设置页。如果界面缺少环境管理入口，尝试浏览器菜单里的“桌面版网站”；仍不可用就改用电脑完成首次配置。

日常启动：在 QQ 私聊复制完整执行指令，打开 ChatGPT 中可用的 Codex Cloud 任务入口，选中已发布的字幕环境，新建任务并粘贴。处理结果会回到网站，手机上也能下载。

本项目没有在每一款安卓系统或原生 ChatGPT 应用版本上完成配置入口验收。浏览器兼容情况和账号能否使用 Cloud，需要以实际界面为准。官方环境配置说明见 OpenAI Docs。

状态怎么理解

看到的状态含义你应该做什么
上传中文件还没完整登记等完成，不要开始 Cloud 任务
待审批等组长检查补充必要说明
待人工启动已批准，但还没在 Cloud 发出任务组长核对并粘贴执行指令
处理中Cloud 已领取并有租约看最近更新时间，不重复启动
需要核对某次请求结果不确定保留账本，核查后再恢复
成功字幕和报告已回传安排人工审核
已取消当前作业停止不再执行它的旧指令

如果页面长时间没变化，先刷新状态和查看故障编号。不要把“没刷新”当成“没执行”，重复启动可能产生额外费用。

字幕账号查看当前网站绑定状态

群绑定指令按机器人返回的整行内容复制，并在群内 @ 机器人。不要用 QQ 群号代替开放平台给机器人的群身份，也不要把其他人的绑定码拿来使用。

提醒检查在北京时间 00:00、07:00、12:00、16:00 进行。错过某个时段或服务器当时停机时，通常要等下一时段；它不保证秒级通知。群聊和私聊分别记回执，一路异常不会被当成两路都成功。

密码、密钥与删除

  • 忘记网站密码：在登录页选择找回密码，使用该账号已验证且能收信的邮箱。组长也走同一方式。没有可用邮箱时，由有权限的云账号管理员通过腾讯云官方用户管理恢复；原密码不能从本项目读取出来。
  • 云执行密钥丢失：无法再次显示原值。确认没有未完成作业后撤销旧身份，新建并重新配置。
  • 已撤销身份：可删除到身份回收区，也可恢复显示；恢复不会重新开启执行权限。
  • 项目/任务的普通删除：进入回收站，可按权限恢复。
  • 永久删除：仅指定组长可用，并受视频保留期与执行中任务保护。清空后不能靠网站回收站恢复。
  • 原视频：启用清理功能后，上传完成起至少保留 7 天，到期在后续检查中清理；字幕和报告继续保留。运行中或待核对的作业会暂停清理。

遇到问题，优先复制网站提供的安全反馈摘要。不要把完整日志、密码、API Key、下载签名或未公开字幕发到公共 Issue。
