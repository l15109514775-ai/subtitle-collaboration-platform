# 自定义域名、备案与 HTTPS

域名可以买在阿里云，网站放在腾讯云 CloudBase；不必因此转移域名或更换 DNS 服务商。以下说明采用占位地址，请使用自己的域名与控制台给出的准确记录。

## 三项容易混淆的事情

| 事项 | 用途 | 是否等于网站可上线 |
| --- | --- | --- |
| 域名实名认证 | 确认注册持有人 | 否，不等于 ICP 备案 |
| SSL DNS 验证 | 证明域名控制权，以签发 HTTPS 证书 | 否，不需要先把网站接到公网 |
| ICP 备案与接入 | 满足中国内地网站接入要求 | 仍需绑定托管、解析与证书并验收 |

网站使用中国内地 CloudBase 时，请先完成适用的备案及接入要求。名称、主体和实际用途需要一致；更改名字不等于改变网站性质，个人/组织适用性请向备案专员确认。

## 1. 检查备案资源

CloudBase 官方文档列出的条件为个人版及以上、环境剩余有效期超过 6 个月、开启云托管固定公网 IP。也可以核查已有符合条件的云资源。不要未经确认就续费、创建 NAT 网关、购买证书或升级边缘加速。条件及费用以办理时的官方界面为准。

进入 CloudBase 环境的备案管理，再进入腾讯云备案系统。身份证件、人脸、短信或电话核验由账户持有人在官方页面完成，不交给机器人或放入 GitHub。

## 2. 申请证书并完成 DNS 验证

1. 在腾讯云 SSL 控制台申请所需证书，确认域名覆盖范围和有效期。
2. 使用 DNS 验证时，从申请详情读取准确的记录名称、类型和值。不要猜测 TXT/CNAME，也不要照抄别人的验证值。
3. 在实际 DNS 托管商控制台检查已有记录，添加无冲突的验证记录；需要覆盖或删除已有记录时先核实影响。
4. 用公共 DNS 查询验证，再回证书控制台确认“已签发”。备案未通过不妨碍此类 DNS 控制权核验，但仍不得提前接入内地网站。
5. 外部 DNS（例如阿里云）不能直接使用腾讯云 DNSPod 自动添加 DNS；可以手动验证，不必迁移 NS。

CloudBase 后续可以直接关联腾讯云证书，一般不需要下载私钥。若确需手动部署，将私钥留在受控部署系统，不能提交到仓库、聊天或日志。

## 3. 备案通过后绑定 CloudBase

1. 打开 HTTP 网关的域名及路由，检查是否已有此前备案失败留下的配置。优先编辑已有配置，避免重复创建。
2. 选择有效证书，保持所需接入方式。当前项目使用云开发接入，不要求额外购买边缘加速。
3. 根访问路径 `/` 关联静态网站托管。若网站从“文件管理”上传，选择“文件”，资源路径填写 `/`；使用托管应用部署的站点应选择对应应用，不能混用。
4. 等待域名状态变为正常，复制平台实际生成的 CNAME。
5. 到实际 DNS 托管商添加主机记录 `@`、类型 CNAME、值为平台给出的目标，不要把域名指向 QQ 机器人服务器。保留现有验证记录；避免与已有入口记录冲突。
6. `www` 是独立域名入口；即使证书包含它，也需要对应托管绑定和解析。不要只添加 DNS 就声称 `www` 已配置。

公开登录 HTML 不应依赖绕过认证才能加载。业务接口与私有文件继续使用已有服务端认证、授权和 RLS，不要因配置新域名而关闭这些保护。

## 4. 验收

- 公共 DNS 的 CNAME 与平台给出的目标一致。
- 浏览器正常加载 HTTPS，无需忽略安全警告；证书域名、到期时间和完整证书链正确。
- 首页、脚本、样式、图片均成功；浏览器无新增脚本错误。
- 检查新来源的登录与业务接口 CORS；不要为了通过检查开放任意来源。
- 原账号在新域名重新登录，无需重新注册。旧域名会话不自动迁移。
- 使用自有测试账号验收申请、审批、上传和下载。CORS 预检成功不等于完整登录已测。
- 按备案要求展示实际备案号与链接；需要公安联网备案时由主办者继续办理。不要在示例源码填写他人的备案号。

QQ 消息和历史执行指令可能仍含旧网址。准备切换通知链接时，先检查插件配置和来源文件；仅配置域名不会自动重写历史消息。

## 5. 90 天免费证书如何续期

免费证书续期实质是申请新证书，再替换部署，并非延长旧证书。建议到期前 30 天启动免费快速续期，前 15 天完成替换，前 7 天再次核查。

重新从新申请读取验证值；需要覆盖旧记录时先确认。新证书签发后在 CloudBase 域名编辑页更新关联，再验证公网实际返回的新指纹、到期时间和证书链。保留旧配置用于受控回滚，不应回退到已过期证书。

腾讯云支持部分云资源的证书托管替换，但“申请/续期”“DNS 验证”“部署替换”是三个步骤。免费快速续期、付费自动续费与自动部署不能混为一谈。当前源码不自动创建任何证书续期任务；如需自动化，应单独设计最小权限凭据、审批、失败告警和回滚。
