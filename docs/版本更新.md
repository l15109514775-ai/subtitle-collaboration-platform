# v0.2.0-beta.1：内测版更新与升级

## 后续修复（main，2026-10-27）

注册按钮附近增加可见状态与必填项提示，展示邮箱核验、账号创建和成员身份检查的进度；认证请求增加 30 秒超时，失败不自动重试。邮箱验证码已核验但后续失败时，清除已使用的验证状态并提示重新获取或尝试已有账号登录。19 个注册反馈模拟用例和 42 项页面回归通过；未创建真实账号，用户报告的实际注册卡点仍需用新的可见提示继续确认。此修复位于 main，不改变已经发布的 beta.1 标签和下载包。

发布日期：2026-10-27。此版本用于小范围内测，尚不宣称生产稳定版。

## 这次更新

- 网站名称统一为“灯塔字幕札记”，更新浏览器标题、侧栏、页脚、反馈摘要和离线教程标题；GitHub 仓库名称与地址保持不变。
- 修复注册页允许大写、数字开头、英文句点和错误长度用户名，随后被认证接口拒绝的问题。
- 新用户名为 6–25 位，以小写字母开头，其余允许小写字母、数字、下划线和短横线。手机输入框关闭自动大写，并提供中文示例；不自动改写用户输入。
- 用户名格式在邮箱验证码核验前校验，格式错误不会消耗验证码。已有账号的用户名密码登录与已有邮箱验证码登录流程保持兼容。
- 增加 12 个隔离注册流程用例，覆盖边界及拒绝路径；所有认证请求均为模拟，不创建账号，不发送邮件。
- 补充阿里云 DNS、腾讯云 CloudBase、备案与 90 天证书维护指南。DNS 验证不等于网站已上线，证书签发也不代表备案完成。

## 已有 v0.1.1 网站如何升级

1. 备份当前静态托管文件，并记录现有环境 ID、网站地址与配置。私钥、Token 和成员数据不要上传公共仓库。
2. 下载本版本，在新的本地输出目录运行配置工具，继续使用自己的环境 ID、HTTPS 地址与现有授权渠道。不要直接将仓库的示例文件覆盖到线上。
3. 本次只需替换配置后的 `site/index.html`、`site/membership.js`、`site/priority-features-20261023-1.js`。新首页带有更新的脚本版本参数，避免旧缓存。
4. **不运行 `INSTALL_ALL.sql`，不重建数据库，不更换 Cloud 身份或机器人凭据。** 本次没有新增数据库迁移，也不要求升级工作器或机器人插件。
5. 刷新页面，检查新名称、注册规则及既有账号登录；自有隔离账号走完注册与组长审批。不要用真实成员账号进行破坏性测试。
6. 如发现问题，将这三个文件恢复到备份版本。升级本身不改变账号、任务、稿件或积分。

新部署仍按 [从零搭建](从零搭建.md) 操作。不要把已有站点升级步骤与空库首次安装混用。

## 工作流边界

仍然使用半自动流程：成员申请 → 组长审批 → QQ 私聊执行指令 → 人工检查并粘贴至 Codex Cloud → 字幕与报告自动回传。没有增加自动登录、自动启动 Cloud 或新的付费服务。

维护者原环境已完成自有域名、HTTPS 证书链、首页、主要静态文件和登录接口跨域预检；这不代替使用者新账户中的登录、注册、上传和完整生产流程验收。

尚未把跨账号部署、真实多连接并发、独立备份恢复或所有安卓机型标为已验证。历史版本的测试基线见 [验证状态](验证状态.md)。
