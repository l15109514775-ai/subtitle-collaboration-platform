WORKSPACE GUIDE

使用说明

先创建一次 API 执行器密钥，再按“申请 → 审批 → API worker 自动领取 → 回传”处理视频。不再需要 API Worker 环境或手工启动指令。

API 执行器与密钥

API 执行器是网站给字幕程序的领取凭据。一个执行器对应一个独立密钥，密钥只在创建时显示一次。

网页里看到的内容具体用途
API 执行器 / 执行器名称用来辨认执行器；名称可以修改，不影响密钥。
创建时显示的执行器密钥填入 API worker 的 SUBTITLE_API_WORKER_TOKEN。旧变量 SUBTITLE_API_WORKER_TOKEN 仍兼容，迁移完成后再移除。

密钥只显示一次，请直接填入 API worker 的安全环境变量，不要发到聊天、QQ 群或放进代码。它与翻译、识别服务的 API Key 分开。

不再使用 API Worker、API Worker 环境或人工粘贴启动指令；API worker 会按自己的执行器密钥自动领取分配给它的任务。

日常字幕流程：上传、审批、API 自动领取与回传
  1. 组员登记视频。在“字幕申请与审批”登记并完整上传视频，单个视频最多 20 分钟、1GB。上传和登记本身不会启动模型。
  2. 组长审核申请。选择 API 执行器，核对时长和调用额度后批准。每个作业最高 400 次文字请求、40 次千问识别请求，实际消耗与费用以接口结果和服务商账单为准。
  3. API worker 自动领取。执行器使用自己的密钥领取已批准任务；不再需要复制 API 指令，也不需要手工选择 Cloud 环境。
  4. 等待自动回传。处理完成后字幕和报告自动回传本站；网站显示交付结果后可下载 ASS / SRT 和报告。
  5. 人工听校与验收。AI 初稿仍需成员听校并提交人工版本，再由符合权限的审核员审核；云端交付本身不产生人工贡献积分。

未启动任务的素材授权过期时，组长可刷新授权；原视频从上传完成起保留 7 天，满期后在下一检查时段清理。执行中或结果待核对时暂缓清理；字幕和报告继续保留。

常见问题：密钥丢失、执行器撤销与删除

密钥没有保存，刷新后不见了怎么办？

网站不提供原密钥再次显示。先核对执行器是否仍有未完成任务，再撤销不再使用的执行器，创建新执行器并更新 API worker 的 SUBTITLE_API_WORKER_TOKEN。

改了执行器名称，需要重配 worker 吗？

不需要。修改名称不改变执行器编号、密钥、权限或额度；只有更换密钥或撤销执行器才需要更新 worker 配置。

为什么已撤销执行器还保留历史记录？

历史任务需要追溯执行来源。组长可在已撤销执行器旁点击“删除执行器”，将其移到“已删除执行器”；恢复记录后仍为已撤销，不会恢复执行权限。

账号、项目、认领、交付、审核与积分
  1. 开通账号：新成员在登录页选择邮箱注册，填写邮箱验证码、组内昵称、用户名及密码。注册后默认无项目权限；组长在“成员管理”的注册申请中选择项目和身份后批准。以后使用用户名和密码登录；邮箱验证码登录作为备用。之前仅用验证码注册的账号不会自动获得密码。
  2. 新建或认领项目：正式组员点击“新建项目”即成为负责人。API 发起的项目显示在未认领项目列表，首位认领项目或其中任务的成员成为负责人；释放任务不转移负责人。API 字幕初稿归入校对任务。
  3. 发起任务：选择项目，填写任务类型、要求和原素材位置。剪辑/压制交付视频，封面交付图片；翻译/时间轴/校对交付字幕。
  4. 认领与交付：认领任务后，在任务详情按类型上传视频/图片，或提交字幕文本、读取 SRT、ASS、VTT、TXT 文件。每次提交生成新版本和内容摘要。ASS 下载保留原有样式与特效；SRT 可转换下载为 ASS（默认样式），也可下载原 SRT。
  5. API 初稿：项目负责人可把 API 文本手动导入待认领任务。成员认领后加工并提交人工版本，说明 AI 辅助与自己的实际工作。
  6. 审核与积分：审核员审阅最新版本，退回修改或批准。批准时填写已核验的人工贡献和积分；提交者不能审核自己的交付。
  7. 保留沟通：讨论继续用 QQ 群。在群里 @「字幕助手」发送「菜单」可查看功能；个人任务查询请私聊机器人，并在本站「成员管理 → QQ 账号绑定」完成本人绑定。任务认领、交付和审核继续在本站操作。

组长和项目负责人可删除项目（页面右下角）或任务（任务窗口底部），须输入名称确认。删除进入回收站，可恢复；不会抹除历史贡献或永久清空文件。恢复任务后必要时需重新认领。

视频上限 1GB（1024MB），封面图片上限 20MB。大文件自动分片传输，全部完成才生成交付版本；当前不支持断点续传，失败后需重新上传。下载时请保持本页打开并保持登录。文件会先计算校验，可查看上传进度并取消。原文件存于私有存储，按项目权限访问，预览与下载链接有效期 10 分钟。

忘记密码时，在登录页点击“忘记密码？”，使用已绑定邮箱的验证码重设密码；未绑定邮箱的账号请联系组长核实。重设后用原用户名和新密码登录。
