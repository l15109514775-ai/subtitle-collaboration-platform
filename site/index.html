WORKSPACE GUIDE

使用说明

先配置一次云执行身份，再按“申请 → 审批 → 人工启动 → 自动回传”处理不同视频。PC 与安卓端操作分别列在下方。

先看这里：身份、密钥和云环境的关系

已有云环境配置可用时，可以继续使用同一个身份，不需要每个视频都新建。只有需要更换身份，或身份已到期、额度用完、密钥丢失时，才需要重新配置。

网页里看到的内容具体用途
云执行身份 / 身份备注网站给字幕程序的授权；备注用于辨认，可自行修改。
创建时显示的身份密钥填入云环境的 SUBTITLE_PLATFORM_TOKEN，让字幕程序领取指定任务、更新进度并回传字幕。
subtitle-delivery-20min-active当前工作流实际运行的 Codex Cloud 环境。身份备注相同，不代表密钥已经配对。

密钥只显示一次，请直接在配置表单中保存，不要发到聊天、QQ 群或放进代码。它是本站执行身份密钥，与翻译、识别服务的 API Key 分开；现有 SUBTITLE_PLATFORM_GATEWAY_KEY 和模型凭据保持原配置。

同一环境中的 SUBTITLE_PLATFORM_TOKEN 一次对应一个身份。更换前先处理完分配给旧身份的未完成任务，避免换完后无法领取旧任务。备注里的 Cloud、60s、20min 都不决定视频时长；上限由每次审批决定，最多 20 分钟。

PC 端：配置云执行身份密钥
  1. 在本站复制密钥。组长进入“任务工作台 → 云端字幕交付 → 云执行身份设置”。确需新建时填写容易辨认的备注，点击“创建云执行身份”，再点击“复制身份密钥”。配置完成前保留此页。
  2. 打开现有云环境。在 ChatGPT 网页版或桌面端，进入“设置 → Codex Cloud → 环境”，找到 subtitle-delivery-20min-active，通过“…”菜单选择“编辑”。也可打开 Codex Cloud 设置。
  3. 填写环境变量。在“环境变量 / Environment variables”旁点击“管理 / Manage”，添加或更新下列项目。当前字幕程序需要直接读取此变量，请填写在“环境变量”中。
字段填写内容
名称 / KeySUBTITLE_PLATFORM_TOKEN
值 / Value粘贴刚才复制的完整身份密钥；不要额外添加引号或空格。
  1. 保存并更新环境。保存配置，完成环境编辑流程并选择“重新发布 / Republish”。从更新后的环境新建任务；已有任务保留自己的状态，不应假定它已经切换到新身份。
  2. 回到网站审批时选对身份。选择刚才生成该密钥的身份。网站选中的身份，必须与云环境中保存的密钥配对。保存完成后可点击本站“清除此页密钥”。

这些设置入口依据 OpenAI 官方云环境说明。只修改身份密钥时，不需要重新购买模型 Key，也不需要重建腾讯云环境。

安卓端：使用浏览器配置密钥
  1. 在手机浏览器打开本站。使用组长账号登录，在“云执行身份设置”复制新身份密钥。不要把密钥发送到 QQ 或聊天中转。
  2. 用浏览器打开 ChatGPT。使用 Chrome 或 Edge 打开 Codex Cloud 设置，登录与现有云环境相同的 ChatGPT 账号。手机布局找不到入口时，可在浏览器菜单启用“桌面版网站 / 电脑版网站”。
  3. 编辑同一个云环境。进入“环境”，编辑 subtitle-delivery-20min-active。打开“环境变量 → 管理”，名称填写 SUBTITLE_PLATFORM_TOKEN，值粘贴本站刚生成的完整密钥；其余已有凭据保持原样。
  4. 保存并重新发布。完成后从该环境新建任务；回到本站审批时选择与这串密钥对应的身份。配置完成后清除本站当前页显示的密钥。

安卓 App 不一定显示完整的环境管理入口，本节提供浏览器网页版路径。安卓设备上的 ChatGPT 配置界面尚未实测；若切换桌面版后仍无法编辑，可在 PC 完成这次配置。日常启动时，只有手机端能选到 Cloud 和该环境，才可在手机粘贴执行指令。

日常字幕流程：上传、审批、云端执行与自动回传
  1. 组员登记视频。在“字幕申请与审批”登记并完整上传视频，单个视频最多 20 分钟、1GB。上传和登记本身不会启动模型。
  2. 组长审核申请。选择已配对的执行身份，核对时长和调用额度后批准。每个作业最高 400 次文字请求、40 次千问识别请求，实际消耗与费用以接口结果和服务商账单为准。
  3. 领取执行指令。QQ 机器人按北京时间每天 07:00、12:00、16:00、00:00 集中检查。新申请在已绑定群内 @组长并私聊提醒；审批通过后的执行指令仅私聊组长。也可在网站的待启动云任务上点击“复制云端执行指令”，无需等机器人。
  4. 人工在 Codex Cloud 启动。检查对应作业指令，在 ChatGPT 新任务选择“Cloud”及 subtitle-delivery-20min-active，粘贴整段指令并发送。PC 端可从“工作位置 / Work in → Cloud”选择；安卓端若 App 没有入口，可尝试浏览器网页版。密钥只填配置表单，不粘贴进任务消息。
  5. 等待自动回传。确认任务已在 Cloud 启动后，可以关闭电脑。处理完成时字幕和报告自动回传本站；网站显示交付结果后可下载 ASS / SRT 和报告。完成、失败或需要核对的通知会在下一检查时段私聊组长。
  6. 人工听校与验收。AI 初稿仍需成员听校并提交人工版本，再由符合权限的审核员审核；云端交付本身不产生人工贡献积分。

目前采用半自动流程：审批与粘贴指令启动由组长完成，网站不会自动替你启动 Codex Cloud。显示“运行中”或“结果待核对”时，请先核对原云任务，避免重复执行、重复消耗额度。

未启动任务的素材授权过期时，组长可刷新授权；原视频从上传完成起保留 7 天，满期后在下一检查时段清理。执行中或结果待核对时暂缓清理；字幕和报告继续保留。

常见问题：密钥丢失、身份撤销与删除

密钥没有保存，刷新后不见了怎么办？

网站不提供原密钥再次显示。先核对旧身份是否仍有未完成任务，再撤销不再使用的身份，创建新身份并按上面的 PC 或安卓步骤配置。

改了备注，需要重新配置云环境吗？

不需要。修改备注不改变身份编号、密钥、权限、额度或云环境。把旧的“Cloud 60s”改成便于辨认的名称即可，名称不改变视频时长限制。

为什么已撤销身份还保留历史记录？

历史任务需要追溯执行来源。组长可在已撤销身份旁点击“删除身份”，将其移到“已删除身份”；恢复记录后仍为已撤销，不会恢复执行权限。请以页面显示的到期时间与已领取额度判断身份是否可用。

账号、项目、认领、交付、审核与积分
  1. 开通账号：新成员在登录页选择邮箱注册，填写邮箱验证码、组内昵称、用户名及密码。注册后默认无项目权限；组长在“成员管理”的注册申请中选择项目和身份后批准。以后使用用户名和密码登录；邮箱验证码登录作为备用。之前仅用验证码注册的账号不会自动获得密码。
  2. 新建或认领项目：正式组员点击“新建项目”即成为负责人。Codex 发起的项目显示在未认领项目列表，首位认领项目或其中任务的成员成为负责人；释放任务不转移负责人。Codex 字幕初稿归入校对任务。
  3. 发起任务：选择项目，填写任务类型、要求和原素材位置。剪辑/压制交付视频，封面交付图片；翻译/时间轴/校对交付字幕。
  4. 认领与交付：认领任务后，在任务详情按类型上传视频/图片，或提交字幕文本、读取 SRT、ASS、VTT、TXT 文件。每次提交生成新版本和内容摘要。ASS 下载保留原有样式与特效；SRT 可转换下载为 ASS（默认样式），也可下载原 SRT。
  5. Codex 初稿：项目负责人可把 Codex 文本手动导入待认领任务。成员认领后加工并提交人工版本，说明 AI 辅助与自己的实际工作。
  6. 审核与积分：审核员审阅最新版本，退回修改或批准。批准时填写已核验的人工贡献和积分；提交者不能审核自己的交付。
  7. 保留沟通：讨论继续用 QQ 群。在群里 @「字幕助手」发送「菜单」可查看功能；个人任务查询请私聊机器人，并在本站「成员管理 → QQ 账号绑定」完成本人绑定。任务认领、交付和审核继续在本站操作。

组长和项目负责人可删除项目（页面右下角）或任务（任务窗口底部），须输入名称确认。删除进入回收站，可恢复；不会抹除历史贡献或永久清空文件。恢复任务后必要时需重新认领。

视频上限 1GB（1024MB），封面图片上限 20MB。大文件自动分片传输，全部完成才生成交付版本；当前不支持断点续传，失败后需重新上传。下载时请保持本页打开并保持登录。文件会先计算校验，可查看上传进度并取消。原文件存于私有存储，按项目权限访问，预览与下载链接有效期 10 分钟。
