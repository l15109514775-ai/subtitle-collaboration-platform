## 本次修复

- `cues.json` 继续使用列表和既有字段，紧凑编码，只交付 id/start/end/text/zh/review。
  逐词结果保留在私有 `primary-cues.json` 和识别检查点，不写入Git。
- 主识别后、后续千问和文字调用前检查确定的体积下限。该检查不承诺未来模型输出大小。
  完成后对九个文件精确校验：每文件500000字节、合计2000000字节。超限保留检查点，
  不自动重试供应商，不扩大网站限额。
- 参考证据的时间窗口使用整批最早开始/最晚结束；导出按时间排序，保留原ID，
  不改变模型批次和既有检查点顺序，避免恢复任务时重复付费。
- 重叠检测覆盖嵌套、非相邻情况，每个受影响字幕最多一项重叠提示，不做自动时间轴修正。
- 允许和纯数字原文一致的数字、比分、百分比和金额；规范化全角形式。
  数值改变、删掉日文正文、任意未翻译外语和字幕标签仍被拒绝。
